# Evaluate AI Agent Multiple Trials Stochastic

This example demonstrates why evaluating AI agents with multiple trials is crucial, especially when agents exhibit stochastic (random) behavior. It simulates a simple agent trying to achieve a goal with random outcomes at each step, showing how a single trial can be misleading compared to the more reliable success rate derived from many trials.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
